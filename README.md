# [Project Title]
Image-Based Quranic Text Authentication System

## Problem statement
Users who access and share Quranic content through digital platforms may encounter Quranic verses in the form of screenshots, scanned pages, or digital images, making the text difficult to verify directly. The problem is that text contained in an image is not immediately available as machine-readable text, while Arabic Quranic text also contains character forms and diacritics that can make automated text recognition challenging. This matters because inaccurate or modified Quranic text shared online may be difficult for users to identify without manually comparing it with a verified Quranic reference.
